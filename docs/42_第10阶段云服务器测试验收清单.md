## 5. API 与权限 smoke

使用独立 admin、finance、boss、sales、front_desk、warehouse、after_sales、taster 测试账号，不在文档中保存 token。

### 5.1 商品与成本

- [ ] admin/finance 可列表、新增、编辑、启停商品。
- [ ] 空名称、空单位、超长值和规范化重名均被稳定拒绝。
- [ ] `DELETE /api/products/:id` 返回 404/路由不存在，商品记录仍可查询。
- [ ] 同一商品启用成本区间重叠返回 `PRODUCT_ACTUAL_COST_RANGE_OVERLAP`。
- [ ] boss 及其他非 admin/finance 角色调用商品成本/毛利接口返回 403。
- [ ] options 只包含启用商品的 `id/name/unit`，无成本、成本历史和审计字段。

### 5.2 订单、品酒和规则

- [ ] 订单和品酒只传 `productName` 被拒绝；只能使用启用 `productId`。
- [ ] 服务端忽略/拒绝客户端伪造名称、单位和成本。
- [ ] 订单按订单日期写入实际成本、成本小计和毛利快照。
- [ ] 修改当前成本后，旧订单快照不变；新订单使用新生效成本。
- [ ] 品酒明细不包含成本和毛利。
- [ ] 销售扣单只按销售扣单规则计算，旅行社扣酒只按旅行社 + 商品规则计算。
- [ ] 修改商品实际成本不改变提成、积分或旅行社扣酒结果。

### 5.3 报表和退款

- [ ] 完整成本返回 `complete` 及精确毛利。
- [ ] 部分成本返回 `partial`，精确毛利为 `null`，包含缺口数和缺口金额。
- [ ] 无成本返回 `unavailable`，不读当前商品成本伪造毛利。
- [ ] 退款订单不自动冲回成本，只返回估算毛利和 `REFUND_COST_REVERSAL_UNAVAILABLE` warning。
- [ ] 成本报表仅 admin/finance 可访问。

# 第 4 阶段云服务器测试验收清单

更新时间：2026-07-01

本文用于记录第 4 阶段“客户和销售订单”在云服务器测试环境的验收范围、执行结果、阻塞项和风险。本文只用于测试环境验收，不作为生产上线验收标准。

第 4 阶段范围包括客户、销售订单、订单明细、旅行团订单关联、财务客户标记、订单财务字段、库管打包字段、售后订单定位和全局标记过滤。不包括二维码销售单、Excel 导出、完整售后单流程、提成积分。

## 19. 修复和复测顺序

1. 恢复 SSH 访问，确认安全组、防火墙、SSH 端口或提供新的登录方式。
2. 进入服务器后先只读检查 `.env` 中的 `DATABASE_URL`，只记录脱敏后的主机、端口和库名，确认库名或实例明确属于测试环境。
3. 检查 `pm2 status`、PM2 日志、Nginx error log，修复 `http://47.120.24.23` 的 502。
4. 确认测试库后执行 `npx prisma migrate status`。
5. 状态无误后执行 `npm run prisma:migrate:deploy`。
6. 执行 `npm run prisma:seed`，确认 seed 数据幂等且只包含 `test/smoke` 示例。
7. 如第 3 阶段云端写入 smoke 尚未完成，先补第 3 阶段旅行团闭环。
8. 按本文第 2 至第 15 节逐项执行第 4 阶段 cloud smoke。
9. 验证结束后恢复全局标记过滤，并保存新的验收记录。

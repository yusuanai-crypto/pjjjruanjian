### A.4 数据切换与回滚步骤

**切换步骤（dry-run → apply）：**
1. `cutover:inventory inventory-preflight`（只读预检）
2. `cutover:inventory inventory-warehouse-bootstrap --warehouses-json config.json`（dry-run）
3. `cutover:inventory inventory-warehouse-bootstrap --apply --env test --backup-confirm --maintenance-freeze --manifest-hash <hash> --warehouses-json config.json`
4. `cutover:inventory inventory-product-mode-plan`（dry-run → apply）
5. `cutover:inventory inventory-serialized-warehouse-plan`（dry-run → apply）
6. `cutover:inventory inventory-opening-import-plan`（dry-run → apply）
7. `cutover:inventory inventory-open-orders-cutover --go-live-at <iso>`（dry-run → apply）
8. `cutover:inventory inventory-open-after-sales-plan`（dry-run → apply）
9. `cutover:inventory inventory-rebuild-verify`（只读校验）
10. `cutover:inventory inventory-cutover-rollback-report --run-id <id>`（只读报告）

**回滚步骤：**
1. 草稿（PENDING）可撤销：直接删除或标记 CANCELLED
2. POSTED 事实（期初单据/占用/出库）：不删除，写冲销/补偿流水
3. 已有 POSTED 流水后不得用 down migration 回滚
4. 最终回滚：关闭新入口 + 恢复整库备份（维护窗口内）

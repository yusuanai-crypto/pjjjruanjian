# 第 1 + 第 2 阶段云服务器测试验收清单

本文用于测试环境验收，不作为正式上线验收标准。当前云端测试 API 为：

```text
http://47.120.24.23
```

Flutter Windows 客户端运行命令：

```powershell
cd D:\jiangjiu\apps\mobile_desktop
C:\src\flutter\bin\flutter.bat run -d windows --dart-define=JIANGJIU_API_BASE_URL=http://47.120.24.23
```

## 1. 当前系统状态边界

- 第 1 阶段已接真实后端：登录、Bearer token、会话恢复、角色权限菜单、员工账号管理接口、全局“只查询已标记信息”开关、操作日志。
- 第 2 阶段已接真实后端的客户端路径：登录页、会话恢复、后端菜单进入主页面、全局标记查询开关、旅行团录入和标记、待处理旅行团列表、订单录入保存、订单管理列表和标记、旅行团离店备注、财务概览、对账表读写。
- 第 2 阶段仍为 UI 骨架或局部假数据：旅行团查询、积分表、二维码销售单、品鉴师总结、库管打包、售后开单、数据分析、AI 助手。
- 验收时不要把 UI 骨架页面当成完整业务闭环；只验入口、菜单权限、页面可打开、占位状态清晰。

## 11. 云服务器排错速查

| 现象 | 优先检查 |
| --- | --- |
| 客户端提示无法连接服务器 | 地址是否为 `http://47.120.24.23`；服务器 `curl -i http://127.0.0.1:3000/api/auth/me`；外网 `curl -i http://47.120.24.23/api/auth/me`；Nginx 错误日志 |
| 登录提示账号或密码不正确 | `.env` 中 `SEED_ADMIN_PASSWORD` / `SEED_DEMO_PASSWORD`；是否重新执行过 seed；`users` 表中用户是否 active |
| 登录后马上回登录页 | `AUTH_TOKEN_SECRET` 是否变化；客户端本地 token 是否旧；`/api/auth/me` 是否返回 401 |
| 某角色菜单不对 | `server/api/src/modules/auth/roles.js` 的 `ROLE_MENU_IDS`；客户端 `destinationsForBackendMenus` 映射 |
| 业务页面列表为空 | seed 是否生成演示数据；全局标记查询开关是否开启；角色数据范围是否过滤 |
| 保存时报 403 | 当前角色是否在后端 `requireAnyRole` 白名单；客户端是否展示了不该展示的入口 |
| 保存时报 500 或 Prisma 错误 | `pm2 logs jiangjiu-api --lines 100`；`npx prisma migrate status`；MySQL 表结构是否完成迁移 |
| 页面是静态假数据 | 先确认该页是否在本文标注为 UI 骨架；骨架页只验入口和展示，不验真实业务闭环 |

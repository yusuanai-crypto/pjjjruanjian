# 第 10 阶段逐次开发提示词

本文根据 `docs/39_第10阶段商品管理、三类成本与毛利核算开发文档.md` 和 `docs/40_第10阶段商品管理、三类成本与毛利核算Schema差距清单.md` 拆分。每次只复制一条提示词给 Codex；完成、验证并确认当前步骤后，再进入下一条。

## 通用要求

- 每次开始前阅读 `docs/39_第10阶段商品管理、三类成本与毛利核算开发文档.md` 和 `docs/40_第10阶段商品管理、三类成本与毛利核算Schema差距清单.md`。
- 只做当前提示词指定的范围，不顺手做完整库存、批次成本、进销存、自动退货成本冲回或老板查看成本。
- 商品不提供物理删除；商品停用只能通过状态变更完成。
- 三类成本必须保持独立：商品实际成本、销售扣单成本、旅行社扣酒成本不能互相回退或复用。
- 新业务明细必须从启用商品选择；不能用自由文本商品名绕过商品 ID 校验。
- 历史订单必须保留原商品名称、单位和已有计算结果；不能用当前成本伪造旧订单毛利。
- 成本查看权限只开放给 `admin`、`finance`。老板和其他角色的后端响应、导出、AI 工具和日志查询不得泄露成本。
- 不连接生产库，不覆盖生产数据。云端写入只允许在第 11 条且确认是测试库后执行。
- 如发现已有未提交改动，先说明，不回滚、不覆盖、不重写用户改动。
- 每次完成后报告：改动文件、数据库变更、测试命令、未解决风险和下一步建议。

## 03. 导入 16 项初始商品和实际成本

```text
请为第 10 阶段实现一次性可重复执行的初始商品数据导入，并基于根目录商品实际成本.xlsx。

要求：
1. 解析包含 16 项商品的行，按商品名/单位中的 / 拆分 name 和 unit。
2. 初始化全部 16 个商品为启用状态。
3. 按人民币元转整数分写入 ProductActualCost；例如小酱酒 6.5 元写成 650 分。
4. 只写商品实际成本，不复制到 SalesDeductionRule 或 AgencyDeductionRule。

7. 不修改旧订单、旧规则、旧提成、旧积分或旧旅行社汇总。

验证：
- 本地临时数据库执行 seed 两次，第二次不增加行数。
- 核对 16 项名称、单位、实际成本分值。
- 检查迁移/seed 输出没有把实际成本泄露到普通角色接口。
```

## 04. 开发商品 API、成本权限和审计

```text
请开发第 10 阶段商品主数据和商品实际成本 API。

建议接口：
- GET /api/products：仅 admin、finance，可查看商品主数据和三类成本管理字段。
- GET /api/products/options：按业务权限返回启用商品的 id、name、unit，不返回任何成本。
- POST /api/products：仅 admin、finance。
- PATCH /api/products/:id：仅 admin、finance，支持编辑主数据和启用/停用，不提供 DELETE。
- PATCH /api/products/:id/actual-cost：仅 admin、finance，更新实际成本并记录审计。

要求：
1. 后端执行角色校验，不能只隐藏 Flutter 菜单。
2. 老板及其他角色请求成本接口必须 403 或等价无权结果，不能返回成本字段。
3. 启用/停用不能删除 Product；停用后 options 不返回该商品。
4. 商品和实际成本创建、编辑、启用、停用、成本更新写入 OperationLog，保留 before/after。
5. 商品名称 + 单位重复时返回稳定的校验错误。
6. 成本输入使用整数分或明确的元转分校验，拒绝负数和浮点误差。

验证：
- admin、finance、boss、sales、warehouse、after_sales、taster、front_desk 权限测试。
- 成本字段接口、列表、详情、导出和错误响应的泄露测试。
- 商品不可 DELETE、停用后 options 不返回、历史 ID 仍可查询测试。
```

## 09. 开发商品毛利和成本覆盖报表

```text
请在财务可见的查询/导出中增加商品毛利和成本覆盖信息。

计算：
订单商品收入 = sum(quantity * unitPriceCents)
订单商品成本 = sum(quantity * actualCostCentsSnapshot)
商品毛利 = 订单商品收入 - 订单商品成本

要求：
1. 只有实际成本快照完整覆盖统计明细时，grossMarginCents 才返回可用数值。
2. partial/none 时 grossMarginCents 为 null 或明确不完整，并返回 costCoverageStatus、coveredLineCount、uncoveredLineCount、coveredOrderCount、uncoveredOrderCount、costCoverageWarning。
3. 历史订单无快照时禁止读取当前 ProductActualCost 计算毛利。
4. 只有 admin、finance 可查看成本、成本覆盖细节和毛利；boss 和其他角色继续只能看到其原有非成本数据。
5. 导出列也必须按同一权限和覆盖口径处理。
6. 明确提示本阶段未自动冲回退货成本。

验证：
- 全覆盖、部分覆盖、零覆盖三种数据集。
- admin/finance/boss/其他角色接口、页面、导出回归。
- 旧订单成本覆盖统计不被当前成本改变。
```

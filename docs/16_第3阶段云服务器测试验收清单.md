# 第 3 阶段云服务器测试验收清单

本文用于第 3 阶段旅行团管理在测试环境的验收，不作为生产上线验收标准。

测试 API：

```text
http://47.120.24.23
```

测试数据命名要求：临时导游、旅行团、品酒明细、备注、临时员工等名称必须带 `test` 或 `smoke` 标识。

注意：不要在验收记录、截图、日志摘录中写入真实密码。

## 1. Smoke Test 当前结果

| 项目 | 结果 | 说明 |
| --- | --- | --- |
| 公网 API 连通性 | 已通过 | `GET /api/auth/me` 返回 401，说明公网入口和鉴权链路可达 |
| SSH 后端目录检查 | 已通过 | 后端目录为 `/opt/jiangjiu/server/api` |
| 运行环境检查 | 已通过 | 云端 Node.js 和 npm 可用 |
| `.env` 非敏感键检查 | 已通过 | 已确认存在 `DATABASE_URL`、`SEED_ADMIN_PASSWORD`、`SEED_DEMO_PASSWORD`、`PORT` 等键 |
| Prisma 迁移状态 | 已通过 | `npx prisma migrate status` 显示当前 schema 已是最新 |
| `prisma migrate deploy` | 未执行 | 写入型命令被安全审查阻止，原因是当前数据库名为 `jiangjiu`，没有明确 `test` 或 `staging` 标识 |

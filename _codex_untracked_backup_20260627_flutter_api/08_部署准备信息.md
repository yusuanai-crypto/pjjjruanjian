## Nginx 反向代理

当前已确认：

- Nginx 已安装：`nginx/1.24.0 (Ubuntu)`。
- `nginx.service` 处于 `active (running)` 状态。
- Nginx 已启用开机自启。
- 配置目录 `/etc/nginx/conf.d` 和 `/etc/nginx/sites-enabled` 存在。
- 当前默认站点配置文件为 `/etc/nginx/sites-enabled/default`。
- NestJS 后端由 `node` 进程监听 `3000` 端口。
- 后端本机直连 `/api/auth/me` 返回 `401 AUTH_TOKEN_REQUIRED`，说明路由和鉴权逻辑正常。

当前 HTTP 反向代理目标：

```text
80 -> Nginx -> 127.0.0.1:3000
```

Nginx 配置要点：

```nginx
server {
    listen 80 default_server;
    listen [::]:80 default_server;

    server_name _;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

验证命令：

```bash
sudo nginx -t
sudo systemctl reload nginx
curl -i http://127.0.0.1:3000/api/auth/me
curl -i http://127.0.0.1/api/auth/me
```
